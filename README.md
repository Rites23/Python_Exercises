This repository contains **Python exercises**. These exercises cover **Python basics** and foundational concepts.

---

## Contents:

### 1. Expressions, Variables & Operators
- Exercises to practice basic expressions, variables, and operator usage.

### 2. Conditional Statements
- `01_A_conditionals_exercise`  
  Exercises focused on `if`, `elif`, and `else` statements.

### 3. Functions
- `02_functions`  
  Exercises covering function creation, arguments, return values, and scope.

### 4. Loops
- `03_loops`  
  Practice with `for` and `while` loops, including nested loops.

### 5. Lists
- `04_List_Exercise`  
  Exercises on list creation, indexing, slicing, and common list operations.

### 6. Nesting
- `05_nesting`  
  Practice with nested data structures such as lists within lists and dictionaries.

### 7. Dictionaries
- `06_dictionary`  
  Exercises on creating, accessing, and manipulating dictionaries.

### 8. Decomposition Patterns
- `07_decomposition_pattern`  
  Exercises focused on breaking problems into smaller, manageable functions.

---

## How to Use:

1. Clone the repository:  
```bash
git clone https://github.com/Rites23/Python_Exercises.git
```

2. Navigate to the exercise folder:
```bash
cd Python_Exercises
```
3. Run any exercise file with Python:
```bash
python filename.py
```
### Skills & Learning Outcomes:

Completing these exercises provides experience in:  

- Writing clean, modular Python code using functions.  
- Applying control flow with conditionals and loops.  
- Working with core data structures, including lists, dictionaries, and nested structures.  
- Decomposing problems into smaller, reusable functions.  
- Preparing code for testing, debugging, and professional project structure.  

These skills provide a strong foundation for building AI knowledge bots and larger Python projects.
